# Lap Time Checker

카메라의 선택 영역에서 움직임을 감지해 랩타임을 기록하는 정적 웹앱입니다.

## 사용법

1. 카메라를 시작합니다.
2. 영상에서 자동차가 통과할 지점을 드래그해 ROI를 지정합니다.
3. `배경 학습 30/30` 뒤 `감지 준비`가 표시되는지 확인합니다.
4. 측정 시작을 누릅니다. 측정 시작 자체는 배경을 초기화하지 않습니다.
5. 실제 통과가 확정되면 그때만 배경을 초기화하고, 30프레임 이상 재학습 + cooldown 후 다시 감지합니다.

## 감지 방식

Android 앱의 OpenCV MOG2 동작감에 가깝게 만들기 위해 웹 감지기를 다음 순서로 처리합니다.

- 최대 ±4 처리 픽셀의 카메라 미세 흔들림 정렬 보정
- 자동노출/조명 변화의 전역 밝기 보정
- 픽셀별 배경 평균과 노이즈 분산 학습
- YCbCr 기반 전경 판정(저채도에서 불안정한 Hue 오검지 방지)
- 고립된 한 픽셀 노이즈만 제거
- 측정 중 감지 기준을 넘었을 때만 통과 확정 및 재학습
- 측정 대기 중에는 초기화 없이 변화한 배경도 계속 적응

`배경 History`는 감지 중 정상 배경이 새 영상에 적응하는 속도를 조절합니다. 값이 클수록 천천히 적응합니다.

설정은 브라우저에 저장됩니다. 카메라는 HTTPS 또는 localhost에서만 사용할 수 있습니다.
