# Lap Time Checker

카메라의 선택 영역에서 움직임을 감지해 랩타임을 기록하는 정적 웹앱입니다.

## 사용법

1. 기기를 삼각대 등 흔들리지 않는 곳에 고정하고 카메라를 시작합니다. 손에 들어도 동작하지만 고정할 때 가장 정확합니다.
2. 영상에서 자동차가 통과할 지점을 드래그해 감지 영역을 지정합니다. 한 차선 폭에, 진행 방향으로 차 길이의 2~3배가 가장 안정적입니다.
3. `배경 학습 30/30` 뒤 `감지 준비`가 표시되는지 확인합니다.
4. 측정 시작을 누릅니다. 첫 통과에서 타이머가 시작되고, 이후 통과마다 랩이 기록됩니다.
5. 통과가 확정되면 배경을 초기화하고, 30프레임 이상 재학습 + 재감지 대기시간 후 다시 감지합니다.

카메라가 켜져 있는 동안 화면이 꺼지지 않게 유지합니다(지원 브라우저). 화면이 꺼지거나 다른 탭으로 가면 측정이 멈춥니다.

## 감지 방식

배경은 잡지 않고 "지나가는 것"만 잡기 위해 여러 단서를 함께 씁니다.

1. **카메라 밀림 따라가기**: 화면 전체로 밀림(최대 ±12 처리 픽셀)을 재고 그만큼 감지 영역을 따라갑니다. 감지 영역 안에서 ±2 픽셀을 더 맞추고, 천천히 계속 밀리면 다시 학습하지 않고 배경을 옮겨 따라갑니다.
2. **이웃 범위 비교**: 픽셀을 배경의 같은 자리뿐 아니라 이웃 3×3의 값 범위와 비교합니다. 무늬가 촘촘한 배경이 1픽셀 어긋나도 변화로 치지 않습니다.
3. **옅은 변화와 뚜렷한 변화**: 색은 그대로인데 밝기만 조금 변한 곳(그림자·조명일 수 있음)은 "옅은 변화", 색이 다르거나 밝기가 크게 다른 곳은 "뚜렷한 변화"입니다.
4. **덩어리 판정**: 주변도 함께 변한 덩어리만 남기고, 그중 뚜렷한 변화가 충분히 든 덩어리만 물체로 셉니다. 그림자는 통째로 빠지고, 배경과 색이 비슷한 차는 바퀴·창 같은 뚜렷한 부분 덕분에 통째로 잡힙니다.
5. **움직임 확인**: 변한 곳이 앞 프레임과도 다를 때(지금 움직이는 중)만 통과로 칩니다. 초점·밝기 조절처럼 서서히 생긴 변화는 통과가 아닙니다.
6. **화면 전체 상황**: 급하게 흔들린 순간의 변화는 통과로 치지 않습니다. 화면 전체가 가려졌다가(손 등) 0.8초 안에 원래대로 돌아오면 통과이고, 돌아오지 않으면 조명 변화로 보고 배경을 다시 배웁니다.
7. 머물러 있는 변화는 1~3초 안에 배경으로 받아들입니다(OpenCV MOG2와 비슷한 동작).

5·6번은 `흔들림·조명 변화 무시`를 끄면 건너뜁니다.

## 설정

- **감지 기준 / 감지 기준 자동**: 물체로 센 면적이 감지 영역의 몇 %를 넘으면 통과인지입니다. 자동이면 최소 3%에서 시작해, 평소 남는 변화와 최근에 튄 값(손떨림 등)의 두 배보다 위로 스스로 올립니다. 끄면 슬라이더 값을 씁니다.
- **흔들림·조명 변화 무시**: 흔들림·그림자·조명 변화로 생기는 가짜 랩을 막습니다.
- **측정 중 초점·색 고정**: 지원 기기에서 카메라가 초점·색을 다시 맞추지 않게 합니다. 기본은 꺼짐입니다.
- **배경 History**: 배경이 새 영상에 적응하는 구간의 상한(프레임 수)입니다. 클수록 천천히 적응합니다.
- **재감지 대기시간**: 통과 후 다시 감지하기까지의 최소 시간입니다.
- **감지 상태 보기**: 버튼 바로 아래에 감지 영역의 판정 그림과 수치(변한 면적·움직이는 면적·기준)를 보여줍니다. 흰색은 물체로 센 곳, 회색은 세지 않은 옅은 변화입니다.

## 한계

- 배경과 밝기·색이 모두 비슷하고 뚜렷한 부분이 전혀 없는 물체는 그림자와 구별할 수 없어 잡지 못합니다.
- 아주 진하고 빠른 그림자(원래 밝기의 60% 아래로 어두워짐)는 물체로 셀 수 있습니다.
- 아주 느리게 지나가는 물체는 "움직이는 중"으로 보지 않아 잡지 못할 수 있습니다.

## 랩 표시

- `통과 누락 의심`: 최근 랩의 약 2배 이상. 통과를 한 번 놓쳤을 수 있습니다.
- `오감지 의심`: 최근 랩의 절반 이하.
- `영상 끊김`: 그 랩 도중 영상이 평소보다 길게 끊겼습니다.
- `흔들림`: 그 랩 도중 흔들림으로 감지를 잠시 막았습니다.

랩타임은 프레임이 찍힌 시각으로 계산합니다. 오차는 프레임 간격 정도입니다(30fps 약 ±0.03초, 60fps 약 ±0.02초).

## 시험

```
node tests/state-test.js   # 상태 전환과 핵심 규칙
node tests/sim.js          # 가상 영상 모의 시험(수 분 걸림)
```

실제로 찍은 영상으로도 확인할 수 있습니다(ffmpeg 필요).

```
node tests/video-prep.js <영상 파일> <프레임 폴더>/<이름>   # 브라우저와 같은 방식으로 줄여 저장
node tests/video-eval.js <프레임 폴더> [이름 일부]            # 놓침·가짜 통과 집계. 정답은 프레임 폴더의 cases.json
```

설정과 기록은 브라우저에 저장됩니다. 카메라는 HTTPS 또는 localhost에서만 사용할 수 있습니다.
